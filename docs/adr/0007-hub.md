# 0007. Hub on Proxmox

- Status: Accepted
- Date: 2026-10-27

## Context

Manara needs somewhere to collect telemetry, alert maintainers and run dashboards. A Xeon D-1541 server is available at the Manara office.

## Decision

The hub runs Proxmox with these LXCs:

| LXC | Role | When |
|---|---|---|
| `zabbix` | Monitoring and alerting | Phase 1 |
| `grafana` | Dashboards | Phase 1 |
| `ops-ha` | Manara's own HA; maintainer phones enrol here for alerts | Phase 1 |
| `ingest` | HTTPS endpoint, per-site bearer token; pushes to Zabbix, later TimescaleDB | Phase 1 |
| `timescale` | Long-term time series | Later |
| `ml` | Analytics and anomaly detection | Later |

The hub is reachable only through its own Cloudflare Tunnel.

## Consequences

- Office power and internet are now part of monitoring's availability. Sites buffer telemetry while the hub is down ([ADR 0008](0008-telemetry.md)).
- Maintainers use the same app and enrolment flow as clients, enrolled against `ops-ha`.
- The hub also hosts the self-hosted Actions runner that holds the APK signing key ([ADR 0010](0010-free-tier-mvp.md)), so it needs backup and access control to match.
